Overflow

A day holds at most 10 pending tasks per board. Add an 11th and it overflows to the next free day — a built-in nudge against overcommitting.

Projects & the Main page

Create as many boards as you like ("personal", "house", …) with the + button. The Main view lists every board's open tasks in one place, grouped by project.

Links in tasks

Any URL you type in a task becomes a clickable link that opens in a new tab. Completing a link task closes its step pane.

AI subtasks

🧠 The assistant

With the header's 🧠 switch on, adding a task instantly opens a pane of up to 10 specific steps — real decisions, real links, real prices, not "make a plan". Click ↺ on an open task to regenerate them.

No Anthropic API key on the server? You get sensible placeholder steps instead — everything else works the same.

Assign steps

Every step shows its suggested owner: 🧠 for the AI agent, 👩 for a human. Click the emoji to assign it; click → on an AI step to dispatch it. Assigned tasks leave your board and appear on the assignee's; they can return them, which puts them back on yours today.

Power moves

Chain a series

Drag a task onto another to make it the next step of a series. Members show a countdown in their circle (steps remaining), light up with connecting threads on hover, and reschedule together — move one and every later step shifts by the same amount.

Unlink a step ✂️

Hovering a chained task reveals scissors — click to cut its link to the previous step. It becomes the start of its own series; nothing else moves.

Lock a deadline 📅

Click a task's 📅 to lock it to a date. Locked tasks (🔒, amber edge) never spill forward — a real deadline. On its deadline day the task text turns red. Shift+Option+click a task to quick-lock it to the day it's on.

Held to the past

When a locked task's day passes unfinished, the calendar doesn't let you look away: the board's first day pulls back to that date, and every day before today gets a red border. Your other overdue tasks still spill to today — only the locked one holds its ground. Complete it (or move its deadline) and the board snaps back to today.

Prioritize

Hover a task and press 1, 2, or 3 — red ! marks, most-urgent-first sorting. 0 (or the same number again) clears it.

AI access key

Shift+click the 🧠 switch to enter your AI access key (see below), so this browser gets real AI generation on a protected deployment.

Close things

Esc closes the open step pane or dialog.

Run your own copy

Move Along is MIT-licensed and built to be forked: one vanilla-JS file for the frontend, a small Express API, SQLite with zero native dependencies, no build step. Fork it on GitHub, then: 

git clone https://github.com/<you>/movealong.git
cd movealong/server
npm install
npm start          # open http://localhost:3000 — that's the whole setup

To deploy (Railway, Render, Fly, any Node host): run npm start from server/, attach a persistent volume, and point DB_PATH at it (e.g. DB_PATH=/data/movealong.db) so your data survives deploys. Node 18+ required.

Enabling real AI steps

  1. Get an Anthropic API key (console.anthropic.com) and set it as ANTHROPIC_API_KEY in your deployment's environment variables.
  2. Generate a private access key — any long random string. In your terminal: 
    openssl rand -hex 24
    (or node -e "console.log(require('crypto').randomBytes(24).toString('hex'))")
  3. Set that string as AI_ACCESS_KEY in the same environment variables and redeploy.
  4. Open your deployed app, Shift+click the 🧠 switch, and paste the same string. Do this once in each browser you use.
Why the access key matters: the app has no login, so without AI_ACCESS_KEY anyone who finds your URL can trigger AI calls billed to your Anthropic account. With it set, strangers get free placeholder steps and only your browsers spend real money. Rate limits (AI_LIMIT_PER_IP_HOUR, default 20; AI_LIMIT_GLOBAL_DAY, default 200) cap the worst case either way. Skip both keys entirely and the app still works with placeholder steps.
All environment variables are optional: ANTHROPIC_API_KEY (real AI), AI_ACCESS_KEY (protect your AI spend), AI_LIMIT_PER_IP_HOUR / AI_LIMIT_GLOBAL_DAY (rate caps), DB_PATH (database location), PORT (default 3000).
