# Header, icons, theme and focus

> Read when touching the header, switches, favicon, wordmark, dark mode, focus mode or the chain hint. Moved out of CLAUDE.md verbatim on 2026-09-30; keep adding here, not there.

### Chrome (from Key Design Decisions)
- **One type scale, 13px base.** Components sit on ~11/12/13/14/15px (day headers 14, section names 15, labels 11-12). The old 22px-base split is gone. Only exception: the wordmark.
- **Favicon:** a white chevron on accent blue (`#0ea5e9`) — the forward arrow that moves a task. **Oversized and bleeding off three ends** (fitted inside the tile it read as a media "next" button). **Safari pinned tabs ignore the favicon** and use `rel="mask-icon"` (`favicon-mask.svg`, same builder); without one a pinned tab shows a letter from the **domain**.
- **A letter tile is a Safari-side caching problem, not markup — don't change the icon tags for it.** Verified: all five icon files serve with correct MIME types; `index.html` and `help.html` carry **byte-identical** icon links; the chevron renders in Chrome, a fresh Safari tab, and `/help` — yet Safari showed a letter on `/` and in a bookmark. That's Safari holding an icon cached when the site had none (the favicon shipped hours after the site went up). Its cache is TCC-protected; bookmark icons survive re-adding.
  - **Diagnostic: open a new tab and paste the URL.** If the icon appears, markup is fine.
  - The `rel="icon"` order (SVG first, PNGs after) was suspected and cleared twice. The mask drops the tile and pulls the chevron inside the canvas. Picked from eight variants at 16px (`archive/favicon-variants/build.js`). **Gotcha:** the bleed means the chevron must be clipped to the rounded square; the rasterizer gets that from the tile's alpha, but `svg()` needs an explicit `clipPath` or the SVG grows spikes — verify with `qlmanage -t -s 192 -o <dir> favicon.svg`. `node docs/favicon/build.js` regenerates `favicon.svg`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png`, `favicon.ico` into `server/public/`. Shapes are signed distance functions, supersampled 4x4, PNG/ICO hand-rolled on `zlib` — **no image dependency, don't add one**. Edit the geometry constants and rerun; never hand-edit binaries. Check at 16px.
- **Wordmark:** "Move<span>It</span>" (renamed 2026-09-13) in self-hosted Bricolage Grotesque 800 (`public/fonts/bricolage-grotesque-800.woff2`, ~38 KB) at 17px, "It" in accent blue. The only non-system type in the app.
- **Quiet single-row header:** 44px min-height, blur/white bar with bottom border, full-bleed via negative margins against `body`'s 20px padding. **`position: sticky; top: 0; z-index: 90` (2026-08-16)** — 90 sits above the board and panes, below popups (100) and modals (1000+). Everything whispers (grey, 12-13px). **Four groups, spaced to say so (reordered 2026-09-15/16):** wordmark + `+` · the three switches · dashboard icon + boards · theme/focus/view/account/help. Kevin moved the switches left, next to today's card, the view toggle between focus and the account chip, and the dashboard icon just left of the boards. **`#dashboardLink { margin-left: auto }` and `#projectTabs { margin-right: auto }`** float that middle group; `#assistantSwitch { margin-left: 8px }` separates the cluster from the `+`; `.assistant-switch + .assistant-switch { margin-left: -2px }` keeps the three tight. Order: wordmark · + new project (**glyph only since 2026-08-16**, `title`/`aria-label` carry meaning; 18px, blue, **no resting ring** — the hover *is* the circle) · 🧠 · 🔎 · 📅 switches · tabs. **Icon-only since 2026-08-16**; **titles carry the hidden gestures**: Shift+Click 🧠 (AI key) and 🔎 (budget + live spend). **The pill is gone; the icon IS the switch (2026-08-17)** — `.focus-toggle` vocabulary: grey off, wordmark blue on, `#475569`/`#38bdf8` in dark, no background.
  - **The icons stayed emoji.** A stroked-SVG set was built and reverted the same day: 🧠 🔎 📅 at **16px**, **`grayscale(1)` + `opacity: .45` when off**. Works here and *not* for the focus ghost — 👻 is white, so desaturating leaves nothing. **Tinting an emoji blue does not work** (a filter only rotates hues present; `sepia+hue-rotate` yields a glossy multi-tone object). Comparison: `archive/emoji-tint.html`; abandoned SVG brains in `archive/brain-variants.html` — at 16px an icon is its outline.
  - **(Removed 2026-10-02 — see calendar.md; its menu lives on the preferences page.) The calendar icon always opened its popup** (which carries Turn on / Turn off; toggling from the icon would make Disconnect unreachable).
  - Help copy says "the brain switch" / "the calendar menu", not the emoji. The 🧠/👩 assignee emoji in the pane are labels, unaffected. · theme toggle · **👻 focus toggle** · view toggle · user·project chip · **? help badge**. **View toggle is one icon button** (`#viewToggleBtn`, `.icon-toggle`) showing the view you'd switch **to**, like the theme toggle; inline `<svg>` in `currentColor`. The old `.view-toggle` pill and `viewCalendarBtn`/`viewMasterBtn` are gone (2026-08-14). **The footer bar is the tip bar (2026-09-03):** `#tipBar` shows the hovered element's tooltip. A document-level `mouseover` finds the nearest `[title]`/`[data-tip]` (falling back to `[aria-label]`), **moves `title` into `data-tip`** (suppressing the browser bubble), paints the text; `:empty::before` holds the height. So **every `title` in `index.html` is footer copy** — write it as a sentence on the element it describes (a parent's title wins over a child's aria-label). `help.html` and task/brief pages keep native tooltips. **When nothing is hovered the bar shows a random idle tip (2026-09-12)** — `IDLE_TIPS`, a blue **Tip:** label plus sentence, dealt fresh per page load and per click on the bar, restored when a hover ends. The list is the things a tooltip can't teach: gestures with no control (drag-to-series, drag-to-reorder, 1-9/0, `r`/`g`, Shift+Option+Click, arrow keys, type-anywhere, "list") and the board's own rules (spillover, day counter, 7/day overflow, lock anchoring). If a new feature is only reachable by gesture, add a tip. The "new board" + (start-a-fresh-account) was removed 2026-08-05. **Clicking the user·project chip opens an account popup with Sign out** (2026-08-11) — `clearSession()` and reload; not a security boundary. Theme and AI key survive it. Reuses `.team-popup`/`.lock-popup-menu`, right-anchored.
- **Task-row hover is `#f0f9ff`** (the old `rgba(255,255,255,.05)` was invisible on white). Chain-hover tints are inline and override it.
- **Dark mode** (🌙/☀️ toggle, `localStorage` `movealong.theme`, default light): one `body.dark` block at the end of the stylesheet — slate (bg `#0f172a`, cards `#1e293b`, borders `#334155`, text `#e2e8f0`); accent blue, red and amber unchanged. The icon shows the theme you'd switch **to**. Any new light-background component needs a `body.dark` override. Chain tints computed in `drawChainThread()` — pastel in light, translucent rgba in dark. `help.html` has its own toggle reading the **same** key; its vignettes stay light in dark mode.
- **Focus mode (ghost toggle, `localStorage` `movealong.focus`, default off):** dims every day card but the focused one (`.day-card.dimmed`, opacity 0.3 + desaturate). Per browser.
  - **The focused day is the one the user picked, else today.** `selectedDayIndex` defaults to `0` = the *anchor*, which can be a past-due lock date; `hasPickedDay` (set in `selectDay()`) decides.
  - **Dimmed, never hidden, never `pointer-events: none`** — clicking a dimmed day moves focus.
  - **A series outranks the dimming**: opening a chained task's pane lights every day the chain touches (`focusedDayKeys()` walks `chainInfo`); hovering a member lights its days (`.day-card.chain-lit`, added in `drawChainThread()`, cleared in `clearChainThread()`). `focusedDayKeys()` must run **after `computeChains()`**.
  - **Outline only, no filled pill** (grey `#cbd5e1` off, `#0ea5e9` on) — a tinted background behind an already-bright glyph makes a view preference the loudest thing in the bar.
  - **The icon is an inline SVG, not 👻** — 👻 is white, so greying it was invisible in light mode. Stroke chrome icons in `currentColor`.
- **Chain hint chip:** a dashed dismissible whisper ("Drag a task onto another…") in today's card when the board has 2+ pending tasks and no series (`shouldShowChainHint()`). `localStorage['movealong.hint.chain']` counts session appearances (once per session); retires after **3 sessions**, on dismiss (`'dismissed'`), or once a chain exists.
- Accent is a **sky-blue ramp** (`#38bdf8` bright / `#0ea5e9` fills / `#0284c7` hover), tints `#f0f9ff`/`#bae6fd`. Replaced emerald green — never green. **Red (`#ef4444`) is reserved for semantic warning/overdue**, the one sanctioned exception.

### The header on every page of your own (2026-10-01)
- **Notes, Dashboard, Goals and Lists carry the board's header** (Kevin: "keep the nav bar on all sub pages … the way to get back to your board would be to click on the board at the top"). The "← Back to your board" links are gone.
- **`public/nav.js`** is the one shared file: loaded as the first thing in `<body>`, it writes the header synchronously and injects its own CSS. Everything is namespaced `.mi-nav` so each page's leftover `.theme-toggle`/`.btn` rules can't bleed in. Its theme button keeps **`id="themeToggle"`**, so each page's existing theme script wires it unchanged.
- It holds the wordmark (→ `/`), the four page icons (the current one lit like an active board tab; the notes dot works here too), the board tabs, the theme toggle, `you · team`, and `?`. **A tab sets `movealong.session.projectId` and goes to `/`**, so the board opens on that board.
- **Board-only controls stay on the board**: `+`, the 🧠 🔎 switches, focus, the view toggle, the account popup. `#notesLink { margin-left: auto }` floats the middle group, as on the board.
- **The header CSS is a copy of `index.html`'s `.app-header` rules.** Change one, change the other. `brief.html`, `preferences.html`, `task.html` and `help.html` don't carry it.
